Get It Vac

Caso de estudo · Web Summit Lisboa 2026 (unofficial stand)

An arcade game controlled by an internet-connected mini robot vacuum, with phone multiplayer, photos, augmented reality and anonymous data. We built it in 5 days.

(01) Challenge

The challenge

  • Bring hardware, web and augmented reality together in a single flow, with low latency between the robot and the screen.
  • Measure use without personal data: no cookies, no email, no accounts and no IP addresses.
  • Do it all in 5 days, from the first sketch to the game going live.

(02) Build

What we built

  1. 01

    The game

    A 400 m race through Lisbon's neighbourhoods, in pixel art drawn on canvas.

  2. 02

    The controller

    Microcontrollers and a joystick inside the robot vacuum, connected over Wi-Fi to a WebSocket relay that passes each move to the game.

  3. 03

    Multiplayer

    Up to 5 phones play at the same time. Each person joins with a QR code, with no app and no account.

  4. 04

    Phone version

    A selfie with a tile frame to share, and augmented reality on the game poster.

  5. 05

    Anonymous data dashboard

    A dashboard with sessions, races and multiplayer rounds, with no cookies and no personal data.

(05) Learnings

What we learned

  • Multiplayer is what keeps people playing.
  • The start of the game needs to be easier.
  • Hardware on event networks needs its own network and a plan B.
  • Building in privacy from the start did not stop us from getting useful data.
